# 런치박스애니메이션

아르떼노바 애니메이션 교구와 함께 쓰는 스톱모션 애니메이션 제작 앱이에요.
폰을 가로로 들고 시나리오 → 촬영 → 대사 녹음 → 사운드 → 편집 → 완성 순서로 만들어요.

## 써 보기

- `index.html`을 크롬에서 열면 바로 돼요.
- 폰에서 실시간 카메라까지 쓰려면 https 주소(GitHub Pages 등)에 올려서 열어야 해요.

## 고치기

- 소스는 `src/` 폴더에 있어요. 고친 뒤 `./build.sh`를 실행하면 `index.html`이 새로 만들어져요.
- Claude Code에서 이 폴더를 열면 `CLAUDE.md`에 정리된 내용을 읽고 이어서 작업해요.
